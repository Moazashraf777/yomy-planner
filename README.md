# يومي — منظم الطالب

تطبيق ويب بسيط بلغة Python وFlask لتنظيم المحاضرات والمصاريف والمواعيد الشخصية.

## التشغيل على Windows

1. ثبّت Python 3.10 أو أحدث من https://www.python.org/downloads/ (وفعّل Add Python to PATH أثناء التثبيت).
2. فك ضغط الملف وافتح مجلد `student_life_planner` في VS Code.
3. افتح Terminal داخل VS Code.
4. نفّذ الأوامر التالية:

```bash
py -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python app.py
```

5. افتح الرابط الذي يظهر في الطرفية، غالبًا http://127.0.0.1:5000

## ملاحظات مهمة عن الإشعارات

- اضغط «تفعيل الإشعارات» واسمح للمتصفح بإرسالها.
- تذكيرات المواعيد الشخصية تعمل أثناء فتح الموقع في المتصفح. لو قفلت الموقع أو الكمبيوتر أو المتصفح، فلن يضمن التطبيق إرسال الإشعار في الخلفية.
- تذكيرات المحاضرات محفوظة في الجدول، لكن النسخة الحالية لا ترسل إشعارًا تلقائيًا للمحاضرة المتكررة؛ يمكن إضافة جدولة خلفية لاحقًا.
- البيانات محفوظة في ملف `planner.db` داخل مجلد المشروع. احتفظ بنسخة احتياطية منه.
- هذا إصدار محلي تجريبي، لا ترفعه على الإنترنت ببيانات مالية خاصة قبل إضافة تسجيل دخول وحماية مناسبة.
